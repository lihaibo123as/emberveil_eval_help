## 🏁 里程碑（1.52.0 → 1.75.60）

- **🖌 世界迷雾「编辑模式」+ 独立偏移量数据库 + 地图标注下拉压过地图**（1.75.60）：地图上**逐块拖拽**（未选中的块按下只选中、再按才起拖 · 右键任意位置释放拖拽 · Shift 多选整组）· 图上序号角标常显、**悬停即高亮对应边框、按住即抓手** · 面板十排（位置箭头 · 尺寸 · 选中集 · **两级重置** · 视图开关 · **统一透明度** · **保存（写盘 + 重载）**）；微调结果可**烘成独立偏移量数据库 `MapOverlayOffset.lua`** 随插件发货（生效次序 = 存档 > 文件 > 无）；★地图里的弹窗要盖在地图上 = **宿主 `WorldFrame` + `FULLSCREEN_DIALOG` + 层级现算** —— 真根因是**开全屏地图会隐藏 UIParent**（挂在它下面的帧一个像素都不渲染，这时抬 strata 毫无用处）。

## 快速上手

1. 把要用的**技能拖上动作条**：插件按动作条识别技能（任意职业、任意技能都能入方案）
2. 游戏内输入 `/eh go rescan` 让插件识别槽位（`/eh go` 查看识别结果）
3. `/eh cfg` →「一键宏设置」页 → `[添加技能]` 配好条件；或直接 `[案例模版]` 按职业挑一个一键导入
4. **绑定按键（推荐，全程点点点）**：右键任意方案（战斗信息UI 方案行 或 配置窗方案栏）→「方案管理」→ 快捷键下拉选一个键 → `[保存]`，按下即执行；**备选**：习惯宏的话，新建宏正文 `/run EVAL_GO()` 拖到按键上（两条路等价）
5. **第一次用？** 输入 `/eh guide` 看四步新手指引（开战斗UI → 配第一个宏 → 绑按键 → 看技能日志），首次进入游戏会自动播报一遍
6. 技能没放出来？开「方案技能日志」（配置窗 全局页）后 ` /eh logdump` 查看每次按键的判定明细

## 安装

**方式一：下载发布包（推荐）** —— [Releases 页面](https://gitee.com/xeval/emberveil_eval_help/releases) 下载最新 `EvalHelp-vX.Y.Z.zip`，解压到 `Interface/AddOns/`（解压后应为 `AddOns/EvalHelp/EvalHelp.toc`）：

```
https://gitee.com/xeval/emberveil_eval_help/releases
```

**方式二：克隆源码** —— `git clone git@gitee.com:xeval/emberveil_eval_help.git`，把整个目录放到 `Interface/AddOns/` 并确保目录名为 `EvalHelp`。

目录结构：

```
Interface/AddOns/
└── EvalHelp/
    ├── EvalHelp.toc     ← 目录规则：Folder/Folder.toc
    ├── EvalHelp.lua
    └── README.md
```

## 异常自救（遇到问题先看这里）

1. **先 `/reload`**：技能不识别、界面异常、刚更新过插件文件——绝大多数情况重载即恢复（配置已存盘不会丢）；
2. 技能换了位置/新拖上动作条 → `/eh go rescan` 重扫；
3. 开了调试看决策过程 → `/eh debug`（每个技能为什么放/为什么不放，逐条件 √×）；
4. 仍未解决 → 到 <https://gitee.com/xeval/emberveil_eval_help.git> 提 Issue（附 `/eh st` 状态截图 + 日志文件更有助于定位）。
5. **分享来的方案有些技能不放**：多半是那个光环在你这台机器上还没学过纹理 —— 现在会自动按名字扫描并学下来；`/eh go tex` 看学习表、`/eh go texdel 名字` 删一条重试、`/eh go texclear` 全清；
