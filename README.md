# EvalHelp —— 全职业工具

> 🌍 Languages: **中文** · [English](README_en.md) · [Русский](README_ru.md)（游戏内语言：配置窗右上角国旗切换）

> EmberVeil（1.12.1 / Lua 5.1）**全职业工具插件**：宏正文一行 `/run EVAL_GO()`，规则引擎驱动——**技能五分类**（角色行为/角色技能/宠物行为/目标选取/物品使用）× **49 种条件类型**（分组下拉；成员选取器行另有 4 种「候选者」条件）× 多方案绑定按键，全部可视化配置，不限职业。另附五个内嵌页：**工具箱**（商人 / 社交 / 任务自动化 / 三个助手 / 稀有提醒 / **拾取贴手**）、**任务线 & 装备**（任务线 · 装备 · 四类检索 + 世界地图标注层，依赖 UnrealQuest）、**图标库**（客户端内置宏图标：分组 / 悬停显示路径 / 搜索翻页）、**抓宠帮手**（宠物技能 → 驯服来源 → 跳查刷新点）与**子插件**（可选子插件的启用 / 停用）。

## 🏁 里程碑（1.52.0 → 1.75.39）
- **🎯 技能编辑：光环类条件「名字多选」**（1.75.39）：buff/debuff 十项条件（自身 / 目标 buff·debuff + 队友·团员 + 候选者）的名字格改成**多选**（点按切换、可搜索、可自定义输入，重开下拉勾选态还在）—— **任一选中项命中即通过**（或运算）；「无/缺」方向取对偶（**每一项都该补**才算过，不是「缺一个就过」）；下拉首行写明规则、名字格悬停列出全部选中项 + 方向，日志与条件 trace 直接报「任一命中 → 谁」/「需全部满足 → 谁」；★旧存档零迁移（`cd.s` 照读、单值导出逐字不变）
- **🛡 图层拖拽：定位方块 + 属性守卫 + 守卫快档**（1.75.36f~n，随 1.75.37 发布）：底部条族「按键后整排上浮 / 出战斗不回位 / 重载后错乱」三连报障的最终解 = **每个常驻层一个挂在 UIParent 下的定位方块**（绝对坐标、中心锚 ⇒ 与缩放无关，「互锚链 / 单位口径 / 旧世界坐标」三个坑一次消失；每层一色 + 标题 + 透明度 0.8，编辑模式才显示、关编辑一起隐藏）；**属性守卫** 0.3s 只读巡检、有漂移才写、战斗中只治位置、总开关 = 编辑⇄守护双模式；有东西在动就切 **30 帧/秒有界窗口**（`/eh go 框拖拽守卫 压测` 真机实测每拍耗时）；聊天框只守坐标（尺寸/淡出归客户端）。；1.75.38 补：**姿态条 / 主动作条内单独动作条**也纳入常驻层（每层一个定位方块；键名未动 ⇒ 存档与守卫记录零影响）

- **🐾 抓宠帮手：宠物攻速 + 宠物列表视图**（1.75.36 → 1.75.37）：攻速**按生物个体**（Petopia 552 条逐条对账 552/552；同一家族横跨多档：猫科 1.0~2.0，而 471/552 全是 2.0）—— 技能详情页驯服来源逐只带攻速（查不到写「?」不冒充）、家族 tooltip 带**家族区间 + 快速具名宠全清单**（断牙 1.0 · 扫荡者 1.2 · 虎王 1.4 · 拉克西里 1.5…）+ 狂乱点数；新增**宠物列表视图**（技能⇄宠物切换 · 攻速升序 · 技能列图标化 · 地区名英→中 52/52），把「不在技能转录表里的 12 只稀有宠」也纳入检索。

- **🔎 自动攻击「保持不住」修好 + 探针整备**（1.75.31 → 1.75.35）：自动攻击补按改成**按前实时射程复判 + 有界复查窗口** —— 目标一进射程、或被随后的施法/切目标取消，**≤1.25s 自己补回来，不必等下一次按键**；顺手把删测试后留下的 **487 个孤儿读值口清掉（源码 −185 KB）**，并把 23 条探针命令抽进 `tools/Probes.lua`（toc 预载 + **载入期零副作用**）；战斗UI 技能格描边改「深色底 + 4 条 1px 细金边」。

- **🎨 聊天名字着色附加段 + 按名光环修复**（1.75.27）：「聊天窗名字着色」右侧 [设置] 多选「等级 / 区域」（默认勾等级）—— 形态 `[区域][等级][名字]`（区域=同地图绿 · 等级=难度色 · 名字=职业色链接，照样点名字密语）；名字缓存新增等级/区域两列 + **5 分钟惰性失效**（下次出现走本地重采 + 主动 /who，不做全量轮询）；★修「取消自身buff:名 报身上没有」三层：读名口误判 `SetPlayerBuff` **返回值**（恒 nil ⇒ 按名匹配从未走通，真凶）· 冒号双侧归一 · 认前缀不再改写名字本体（`物品:`/`姿态:` 同族收口）。
- **🧲 拾取贴手（点一次换下一件）**（1.75.26）：拾取窗**开箱即贴到鼠标下**，之后**每点一件立刻把下一件送到鼠标下**（拾光才说「后面没有物品了」）；★挂点是**原生 `OnClick` 跑完之后**、不是按下那一拍（按下就搬会让「抬起」落到别的格 ⇒ **拾到下一件、漏掉这一件**）；★**压实结论运行期自证**（点前后槽位表比对，客户端若往上压实 ⇒ 当场挪回 + 改原地换，绝不漏拾）；另有**品质角标**（金币=金色）与**跟随鼠标**档；★搬窗**只就地平移客户端自己的锚点、绝不 `ClearAllPoints`**（老写法会被客户端补回自己的锚点 ⇒ 同帧两条竖直边把窗**撑变形**；现自带开窗清账 + `/eh go 拾取 修复`）；工具箱「任务」分类也从两个标题合并成一个「任务」组。
- **🎨 日志着色 + 自动攻击默认关 + 模版同步**（1.75.25）：① 方案技能日志按**内容**着色 —— **触发=红**、**跳过=灰**（唯一出口 `wlog`：先判「跳过」再判「触发」，`war:` 前缀与其余行照旧）；② 一键宏「**自动攻击**」开关**默认关闭**（真值 `w.attack == true`，**nil = 关** ⇒ 从没动过开关的旧存档自动变关，明确开过的一直是 true 保持开；三语提示已注明「默认关闭」）；③ 案例模版「雷霆万钧」按**作者最新版**逐条同步（撕裂 `目标血>5 & 怒气>24` · 英勇打击 `怒气>35` · 雷霆一击提到断筋之前 · **末尾新增 `攻击 | 可攻击`** ⇒ 13 条）。
- **🗺 探索层补抓**（1.75.24）：缩放大地图**不再「落闩即止」** —— 只要还有**在用、却还没有原值**的层就自动重新开抓（1 秒一次、有界），修掉「**13、14 探索层未正确应用缩放**」；★**病因**：落闩只数「本轮已就绪」的层，当时**隐藏 / 贴图还没载入**的层不算数 ⇒ 它们稍后显示出来也**永远拿不到原值**，而折算只认有原值的层 ⇒ 同一个缩放值下**一部分折了、一部分没折**；`/ehm mapfit dump` 现在把等待中的层**点名**（长期不为 0 ⇒ 读不到几何或客户端没给贴图）。
- **🤝 队友/团员条件「联合判定」**（1.75.23）：同一行里 **≥2 条队友条件**现在**合并成一次选人** —— 逐候选对**同一个人**判定全部条件、第一个全过者命中且**只切一次目标**；★**病因**：旧版每条队友条件**各自扫全员、各自挑人**（后一条覆盖前一条）⇒ 「血<85 **且**缺恢复」会追着「最缺恢复的人」（可能满血，甚至就是你自己）；单条条件与所有非队友条件**行为不变**，`/eh go 联合 on|off` 可对照。

## 快速上手

1. 把要用的**技能拖上动作条**：插件按动作条识别技能（任意职业、任意技能都能入方案）
2. 游戏内输入 `/eh go rescan` 让插件识别槽位（`/eh go` 查看识别结果）
3. `/eh cfg` →「一键宏设置」页 → `[添加技能]` 配好条件；或直接 `[案例模版]` 按职业挑一个一键导入
4. **绑定按键（推荐，全程点点点）**：右键任意方案（战斗信息UI 方案行 或 配置窗方案栏）→「方案管理」→ 快捷键下拉选一个键 → `[保存]`，按下即执行；**备选**：习惯宏的话，新建宏正文 `/run EVAL_GO()` 拖到按键上（两条路等价）
5. **第一次用？** 输入 `/eh guide` 看四步新手指引（开战斗UI → 配第一个宏 → 绑按键 → 看技能日志），首次进入游戏会自动播报一遍
6. 技能没放出来？开「方案技能日志」（配置窗 全局页）后 ` /eh logdump` 查看每次按键的判定明细

## 异常自救（遇到问题先看这里）

1. **先 `/reload`**：技能不识别、界面异常、刚更新过插件文件——绝大多数情况重载即恢复（配置已存盘不会丢）；
2. 技能换了位置/新拖上动作条 → `/eh go rescan` 重扫；
3. 开了调试看决策过程 → `/eh debug`（每个技能为什么放/为什么不放，逐条件 √×）；
4. 仍未解决 → 到 <https://gitee.com/xeval/emberveil_eval_help.git> 提 Issue（附 `/eh st` 状态截图 + 日志文件更有助于定位）。
5. **分享来的方案有些技能不放**：多半是那个光环在你这台机器上还没学过纹理 —— 现在会自动按名字扫描并学下来；`/eh go tex` 看学习表、`/eh go texdel 名字` 删一条重试、`/eh go texclear` 全清；
