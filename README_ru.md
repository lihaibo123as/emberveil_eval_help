# EvalHelp — Помощник каста для всех классов

> Аддон EmberVeil (1.12.1 / Lua 5.1): макрос в одну строку `/run EVAL_GO()` + движок правил — **5 категорий навыков** (Действия / Навыки / Питомец / Цель / Предметы) × **28 условий** × несколько профилей на разных клавишах. Полностью визуальная настройка, любой класс.
>
> 中文: [README.md](README.md) · English: [README_en.md](README_en.md)

| Модуль | Вход | Что внутри |
| :-- | :-- | :-- |
| 🗡️ Макрос | `/run EVAL_GO()` | Навыки панели, команды питомца, смена цели, предметы; профилей ≤4 на отдельных клавишах |
| ⚙️ Настройки | значок EH у карты · `/eh cfg` | Визуальный редактор профилей/условий, импорт/экспорт текстом |
| 📊 Боевая панель | `/eh ui` | Полосы HP/энергии/цели + строка профилей + иконки навыков (золото = условия выполнены) |
| 🔍 Панель состояния | `/eh st` | Все переменные + разбор условий √× |
| 📝 Журнал | `/eh` | Чат + файл |

## Установка

Скачайте `EvalHelp-vX.Y.Z.zip` из [Releases](https://gitee.com/xeval/emberveil_eval_help/releases) и распакуйте в `Interface/AddOns/` (должно получиться `AddOns/EvalHelp/EvalHelp.toc`).

## Быстрый старт

1. Перетащите навыки на панель действий, нажмите **[Сканировать панели]** (вкладка «Общие») или `/eh go rescan`
2. Создайте макрос с телом `/run EVAL_GO()` и нажимайте клавишу
3. Профили: `/eh cfg` → «Макрос» → [Добавить навык]; Shift+клавиша — смена активного профиля
4. Прямой запуск: `/run EVAL_GO(2)` или `/run EVAL_GO("Имя")`

## Примеры

```
# Профиль: зелья автоматом
- 物品:弱效巨魔之血药水 | 无buff:再生

# Профиль: питомец
- 宠物:攻击 | 战斗中 & 可攻击
- 宠物:被动姿态 | 非战斗
```

Внимание: текст правил (условия, имена навыков, импорт/экспорт) остаётся на языке клиента — переводится только оболочка интерфейса (zhCN/enUS/ruRU, выбор флагами в правом верхнем углу окна настроек).

## Команды

`/eh` журнал · `/eh cfg` настройки · `/eh ui` бой · `/eh st` состояние · `/eh go` статус · `/eh go rescan` скан · `/eh go list` профили · `/eh go io` импорт · `/eh debug` отладка · `/eh help` все команды
