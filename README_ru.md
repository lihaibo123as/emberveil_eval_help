# EvalHelp — Инструмент для всех классов

> 🌍 Языки: [中文](README.md) · [English](README_en.md) · **Русский**（язык в игре: флаги в правом верхнем углу окна настроек）

> Аддон-инструмент **для всех классов** EmberVeil (1.12.1 / Lua 5.1): тело макроса — одна строка `/run EVAL_GO()`, движок правил — **пять категорий навыков** (действия персонажа / навыки персонажа / поведение питомца / выбор цели / использование предметов) × **49 типов условий** (выпадающий список с группами; плюс 4 типа условий «кандидат», появляются только в строке выбора участника) × несколько профилей на разных клавишах. Полностью визуальная настройка, без привязки к классу. Плюс пять встроенных страниц: **Инструменты** (торговец / общение / задания / три помощника / трансляция редких / **добыча под курсором**), **Квесты и вещи** (цепочки · снаряжение · четыре вида поиска + слой меток на карте мира, нужен UnrealQuest), **Библиотека иконок** (встроенные иконки макросов клиента: группировка по префиксу, путь при наведении, поиск и постраничный просмотр), **Помощник питомцев** (способности → источник приручения → точки спауна) и **Суб-аддоны** (включение / отключение необязательных суб-аддонов).
>
> 📌 Текст правил (имена навыков / слова условий / импорт-экспорт) остаётся на языке клиента — переводится только оболочка интерфейса.

## 🏁 Вехи (1.52.0 → 1.75.35)
- **🔎 «Автоатака» больше не слетает + порядок в пробах** (1.75.31 → 1.75.35): долив автоатаки теперь **перепроверяет дистанцию перед нажатием** и держит **ограниченное окно перепроверки** — когда цель входит в радиус или заклинание/смена цели её сбрасывают, она возвращается сама за ≤1.25 с (лишнее нажатие не нужно); также удалено **487 осиротевших тестовых read-port'ов (−185 КБ исходников)** и 23 команды-пробы перенесены в `tools/Probes.lua` (предзагрузка из .toc, **нулевые побочные эффекты при загрузке**); ячейки боевого UI — тёмный фон + рамка 4×1px.

- **🔀 Двухуровневые связи условий (план B) + бесшовное обновление кэша имён** (1.75.28): ячейка связи стала **четырёхтактным переключателем** `&` / `|` / `&&` / `||` (приоритет `& > | > && > ||`) — теперь можно писать **ИЛИ внутри И**: `(A|B) & C`; ★ **нулевая миграция** (старый текст вычисляется идентично, harness из 152 случаев); кэш имён в чате **не удаляет старые значения и обновляется в фоне**; ★ **четыре реальных исправления** (шлюз знал только старый формат ⇒ правило становилось безусловным и срабатывало на каждое нажатие по себе · экспорт терял условия · совместный выбор союзников применялся по члену, а не по старой группе · поиск аур нормализует двоеточия); справка по операторам в редакторе; шаблон «Хранитель одного» заменён живым профилем «Вечная стража» (12 навыков).

- **🎨 Дополнения к цветным именам + починка аур по имени** (1.75.27): у строки «Цвета имён в чате» появился мультивыбор **[Настройки]** (Уровень / Зона; Уровень включён по умолчанию) — формат `[зона][уровень][имя]` (зона = зелёная на вашей карте · уровень = цвет сложности · имя = цветная ссылка, кликабельна); кэш имён получил колонки уровня и зоны с **ленивым TTL 5 минут** (просроченное имя дозапрашивается при следующем появлении: локальный добор + активный /who — без полного опроса ростера); ★«Снятие своего баффа: X пишет „нет на себе“, хотя он есть» исправлено в трёх слоях: читалка имени проверяла **возвращаемое значение** `SetPlayerBuff` (всегда nil ⇒ путь по имени не работал никогда — настоящая причина) · нормализация двоеточия теперь с обеих сторон · разбор префикса больше не переписывает само имя (`item:`/`stance:` — так же).
- **🧲 Добыча под курсором (один клик = следующий предмет)** (1.75.26): окно добычи **при открытии встаёт под мышью**, дальше **каждый клик подводит следующий предмет под курсор** (о конце сообщается только после последнего); ★ обработчик висит **после родного `OnClick`**, не на нажатии (сдвиг окна при нажатии ⇒ отпускание попадает в другую ячейку ⇒ **подбирается следующий предмет, а этот пропускается**); ★ **уплотнение слотов доказывается на ходу** (карты имён слотов до/после клика: если клиент уплотняет, окно возвращается на место и смена идёт на месте); плюс **метки качества** (золото = монеты) и режим **следования за мышью**; ★ окно только **сдвигается на месте, без `ClearAllPoints`** (старый способ позволял клиенту вернуть свой якорь ⇒ две вертикальные привязки **растягивали окно**; теперь очистка при открытии + `/eh go lootcursor fix`). Категория «Задания» в ящике инструментов тоже сведена к одной группе.
- **🎨 Раскраска журнала + автоатака по умолчанию выключена + синхронизация шаблона** (1.75.25): ① журнал навыков профиля теперь красится **по содержимому** — **сработало = красный**, **пропуск = серый** (единственный выход `wlog`: сначала проверяется «пропуск», затем «сработало»; оранжевый префикс `war:` и прочие строки без изменений); ② переключатель «**Автоатака**» теперь **по умолчанию выключен** (`w.attack == true`, **nil = выкл** ⇒ старые сохранения, где его не трогали, автоматически выключаются; явное `true` остаётся включённым; подсказки в трёх языках обновлены); ③ шаблон «Громовая кара» синхронизирован построчно с **последней версией автора** (Разрывающая `tHp<5 & ярость>24` · Героический удар `ярость>35` · Громовой удар перед Подрезанием · новая последняя строка `Атака` ⇒ 13 записей).
- **🗺 Дозахват слоя исследования** (1.75.24): свёртка при масштабе карты больше **не останавливается на защёлке** — если слой **используется, но исходного значения ещё нет**, захват открывается снова (ограниченно, раз в секунду), что исправляет «**слои 13 и 14 не масштабируются**»; ★**причина**: защёлка считала только готовые *в тот момент* слои, поэтому **скрытые или ещё без текстуры** слои позже **уже никогда не получали исходное значение**, а свёртка работает только с записанными слоями ⇒ при одном и том же масштабе часть слоёв свернулась, а часть — нет; `/ehm mapfit dump` теперь **называет** ожидающие слои (если значение не падает до 0 — геометрия не читается или клиент не дал текстуру).
- **🤝 Совместный выбор цели по условиям группы/рейда** (1.75.23): строка с **2+ условиями по группе** теперь выбирает цель **одним проходом** — каждый кандидат проверяется по **всем** условиям, берётся первый полностью подходящий (**одна смена цели**); ★ раньше каждое условие сканировало состав само и побеждало последнее (правило мало-HP **и** нет-бафа могло скастовать на участника с полным здоровьем — даже на вас); одиночные условия и все не-групповые условия работают как раньше, `/eh go 联合 on|off` — переключатель для сравнения.
- **🎯 Квесты и вещи: древо заданий (родитель/потомок) + полоса нужных материалов + настоящая причина пустых описаний** (1.75.14 → 1.75.22): теперь находятся и открываются **все** задания — полная таблица выросла с «751 задания с наградой-снаряжением» до **4018**; ★**настоящая причина** «некоторые описания заданий пустые»: обновление описания разбиралось по **вкладке вида**, поэтому описание одного задания попадало в ветку описания цепочки и искало nil-ключ (**достаточно было прокрутить описание**) ⇒ теперь разбор по трём истинным значениям, данные получили «нужный уровень + награды (выбор/выдача) + имена предметов», а текст переписан на пять разделов; ★**дедупликация списка цепочек**: шаги цепочки **вливаются в её строку** (Ульдаман: 34 строки → 20, с честной подсказкой «влито N»); ★**новая вкладка «Древо»**: строки сайта «открывает / требует» объединяются в **граф родитель-потомок** (1096 связей / 758 родителей / без циклов), отступ = уровень, у нескольких предков пометка «(%d предка)»; ★в строках появился значок «**нуж**» и **полоса иконок нужных материалов** (в одной строке с наградами, тёплый оттенок, при наведении — весь список; **предметы заданий отфильтрованы** по метке `Quest Item` на странице предмета); плюс мультивыбор источника (зоны) и уровней, прокрутка списка колесом и заглушки иконок.
- **🔍 Метки на карте: лупа справа + список категорий + закрытие кликом вне окна** (1.75.13): лупа у правого края карты (текстура взята у аддона заданий, с подтверждением `GetTexture()` и текстовым запасным вариантом) по ЛКМ открывает список категорий с множественным выбором, рядом всегда видно число категорий; ★список закрывается кликом **в любом месте вне него** (новый полноэкранный перехватчик плюс подъём уровня каждого дочернего элемента — подъём родителя **не поднимает детей**, иначе получается чёрный прямоугольник или нерабочие строки); метки **рисуются и на миникарте** (используется собственный рецепт миникарты аддона заданий); ★также: вспышка затемнения карты убрана через `alpha 0 + Hide` (при закрытии не восстанавливается), тестовый каркас полностью удалён (единственный гейт — `node luacheck.js`).
- **🗺️ Исходные значения слоя исследования: только память сессии · очистка при закрытии · перечитывание и пересчёт при каждом открытии** (1.75.5): исходные значения **больше не сохраняются** (старые ключи удаляются, штамп версии не пишется); по требованию пользователя запись **очищается в момент закрытия карты** и **перечитывается с повторным применением масштаба при следующем открытии** — очистка выполняется только после **возврата свёрнутой геометрии к натуральному масштабу и строгой проверки** (иначе свёрнутые значения были бы приняты за исходные = двойное масштабирование); исправлено «**при /reload 0 записей считались завершённым захватом**» (нет подходящих слоёв ⇒ без защёлки, повтор раз в 1 с, затем автодобор); захват больше не перезапускается каждый кадр, масштаб карты не дрожит; исправлено «**текстуры слоя исследования рисуются поверх игрового мира**» (якоря теперь разрешаются в объекты фреймов); новая команда **`/ehm fitnow`** (карта → натуральный масштаб → 2 с → чтение → масштаб → свёртка, с печатью каждого шага) + тихий/подробный режим.

## Быстрый старт

1. Перетащите нужные навыки на панель действий
2. В игре введите `/eh go rescan`, чтобы аддон распознал слоты (`/eh go` — посмотреть результат распознавания)
3. **Привязка клавиши (рекомендуется, только клики)**: ПКМ по любому профилю (строка профиля в боевом интерфейсе или список в настройках) → управление профилем → выберите клавишу → [Сохранить]. **Альтернатива** для любителей макросов: `/run EVAL_GO()` одной строкой и перетащить на клавишу.
4. Быстрый старт с шаблонов: окно настроек → вкладка «Макрос» → [Импорт/Экспорт] → **[Шаблоны]** — библиотека сгруппирована по классам, клик = импорт готового профиля, дальше подгоните под себя
5. **Впервые здесь?** Введите `/eh guide` — руководство из четырёх шагов (боевой интерфейс → первый профиль → привязка клавиши → журнал способностей); при первом входе оно показывается автоматически.
6. `/eh debug` — в чате показывается причина каждого решения при нажатии, удобно настраивать пороги

## Самопомощь при сбоях (при проблемах смотрите сюда)

1. **Сначала `/reload`**: навыки не распознаются, глючит интерфейс, только что обновили файлы аддона — в большинстве случаев перезагрузка всё чинит (конфиг сохранён и не пропадёт);
2. Навыки сменили позицию / новые перетащены на панель → `/eh go rescan` пересканировать;
3. Включите отладку и смотрите процесс решений → `/eh debug` (почему каждый навык кастуется / не кастуется, поусловно √×);
4. Не решено → заведите Issue на <https://gitee.com/xeval/emberveil_eval_help.git> (скриншот состояния `/eh st` + файл журнала сильно помогают локализации).
5. **Чужой профиль не применяет часть способностей**: обычно текстура ауры не изучалась на этой машине — теперь она ищется по имени и запоминается; `/eh go tex` — список, `/eh go texdel <имя>` — удалить одну, `/eh go texclear` — очистить;
