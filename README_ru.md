# EvalHelp — Инструмент для всех классов

> 🌍 Языки: [中文](README.md) · [English](README_en.md) · **Русский**（язык в игре: флаги в правом верхнем углу окна настроек）

> Аддон-инструмент **для всех классов** EmberVeil (1.12.1 / Lua 5.1): тело макроса — одна строка `/run EVAL_GO()`, движок правил — **пять категорий навыков** (действия персонажа / навыки персонажа / поведение питомца / выбор цели / использование предметов) × **60 типов условий** (6 групп выпадающего списка: свои · цели · ауры · группа/рейд · навык/чтение · кандидат — 4 типа «кандидат», появляются только в строке выбора участника) × несколько профилей на разных клавишах. Полностью визуальная настройка, без привязки к классу. Плюс пять встроенных страниц: **Инструменты** (**UI-инструменты** · торговец · группа / общение · задания · три помощника · трансляция редких — **полный список строк в таблице ниже**), **Квесты и вещи** (цепочки · снаряжение · четыре вида поиска + слой меток на карте мира, нужен UnrealQuest), **Библиотека иконок** (встроенные иконки макросов клиента: группировка по префиксу, путь при наведении, поиск и постраничный просмотр), **Помощник питомцев** (способности → источник приручения → точки спауна) и **Суб-аддоны** (включение / отключение необязательных суб-аддонов).
>
> 📌 Текст правил (имена навыков / слова условий / импорт-экспорт) остаётся на языке клиента — переводится только оболочка интерфейса.

## 🏁 Вехи (1.52.0 → 1.75.101)

- **🎒 EH_Bag: покачественная яркость + одноканальное свечение (открытие == возврат фокуса) + интервал ячеек в меню настроек · Макрос: условия «смена / свой предмет / своя экипировка»** (1.75.100 → 1.75.101 / EH_Bag 0.3.31): яркость по ступеням настраивается вручную (`B.QUAL_K`, зелёный 0.80 / синий 1.3225, без авто-нормализации); альфа свечения переведена на **один канал** (4-й аргумент цвета вершины, `SetAlpha` всегда 1 ⇒ **вид при открытии совпадает с видом после фокуса**, коэффициенты действуют линейно); «интервал ячеек» переключается из меню настроек (`B.cgap`). Три новых условия: **смена:слот:предмет** (после выбора предмета выпадает список слотов), **свой предмет** (сумма всех стопок ≥ N), **своя экипировка готова** (эффект использования + кулдаун, читается из невидимой подсказки); высота/ширина кнопок профиля вынесены в две константы в начале файла (`UI_PROF_BTN_H` / `UI_PROF_MIN_W`). DragFrames: одиночный левый клик по значку настроек **сбрасывает свойства рамки** (`dfResetOne`).
- **🎒 Суб-аддон EH_Bag: от нуля до полного набора, и сравнение предметов поддерживает оба механизма** (1.75.91 → 1.75.99 / EH_Bag 0.3.22 → 0.3.30): на вкладке 7 вырос **единый инвентарь**, повторяющий OneBag по пунктам (непрерывная раскладка · свечение качества · сортировка одной кнопкой · обзор по персонажам · отсчёт перезарядки · строка денег со значками монет · **абсолютно самодостаточные ресурсы**: свои текстуры + проба с **негативным контролем** + откат на клиентскую копию, если не определить); в этой партии закрыты три причины = «пустые ячейки при первом открытии ярче, чем после наведения» (**4-й аргумент цвета вершины и `SetAlpha` перемножаются и применяются в разное время** ⇒ alpha идёт через цвет вершины, `SetAlpha` жёстко = 1) · свечение выходило за ячейку и подсвечивало соседей и линии фона (снаружи **должно быть 0**: 492 → 0 пикселей) · «нормализация яркости» свечения **полностью откатана** по просьбе пользователя (яркие ступени больше не затемняются); у каждого суб-аддона теперь свои `README`/`CLAUDE`/`CHANGELOG` и **два отдельных архива**; сравнение предметов исправлено для «слепоты внутри прокси-сумки» (суб-аддон сам сообщает о наведении, оба механизма по одной мерке).
- **🧭 Три правки вёрстки в редакторе навыков + строка профилей в боевом UI держит иконку и имя вместе** (1.75.79 → 1.75.82): у строк условий появились **▲/▼ для перестановки** (записи меняются целиком, а связка `conn` остаётся на месте — она относится к позиции, а не к условию) + цвета функциональных кнопок (перестановка = тёмное золото / добавить = зелёный / удалить = красный) и более широкое окно (с пошаговым откатом, если не помещается); справка о связках стала **одним листом для трёх мест, простыми словами и без `**`** (GameTooltip — простой текст, звёздочки рисуются как есть); три нижние кнопки теперь **в одну строку и по левому краю**; строка профилей измеряет «иконку + имя» **как одну плотную группу** через `max(замер, оценка по символам)` (китайский `GetStringWidth` занижает, и 1 px достаточно, чтобы имя сжалось до «神…»).
- **🏷 Единая формулировка условий «группа / рейд» + 🎨 пять цветов ступеней «белый/зелёный/синий/фиолетовый/оранжевый» + 💎 призывы в помощнике расходников + 🎯 строка профилей боевого UI центрируется группой** (1.75.83 → 1.75.90): **отображаемые имена условий больше не содержат направления** (его задаёт да/нет), и **имя = текстовое обозначение = `cd.name` совпадают** — переименование никогда не трогает сохранения и текст обмена (проверка `tmp/team_label_check.js`: 64 пина + 34 мутации); цвета ступеней = **белый / зелёный / синий / фиолетовый / оранжевый** (божественная перешла с ярко-синего на оранжевый, все четыре места рисования и строка обмена читают один источник); помощник расходников пропускает призывы **по id предмета** (4 самоцвета маны мага + 5 камней здоровья чернокнижника — правило по классу их отсекает: в реальных данных агат маны числится «бронёй»); строка профилей боевого UI центрирует группу «иконка + имя» внутри кнопки (текстовое поле обязано использовать `SetJustifyH("LEFT")`, а не якорь `CENTER`).
- **🎹 Привязки клавиш по персонажу + 💰 цены в наградах за задания + 📋 копирование/вставка в списке навыков + ✂️ экранирование вертикальной черты** (1.75.74): клиент хранит привязки **на аккаунт** (один файл на всех персонажей) ⇒ клавиша, привязанная на персонаже A, остаётся и на B, поэтому аддон ведёт **записи по персонажу и сверяет их при каждой загрузке** (`war.bindByChar[персонаж][профиль]`; **идемпотентно, сохраняем только при реальном изменении**; перед снятием чужого остатка проверяем, есть ли у **этого персонажа** навык в слоте, и мы **никогда не снимаем `ACTIONBUTTON1~12` оптом** — эти имена команд и есть клавиши панели игрока; правило слота — «у команды вообще нет клавиши», а если ничего не подходит, мы **честно сообщаем, что привязать нельзя**, и даём выход (освободить слот / макрос), не отбирая клавиши; новый порт только для чтения `/eh go bind` печатает все 12 слотов); в том же выпуске: цены предметов теперь и в **наградах за задания** (исправление такта + защита от падения), в списке навыков появились правый клик **копировать / вставить** (между профилями, с плашкой буфера и подсказкой у заголовка), а поле импорта/экспорта стало **многострочным** с **экранированием вертикальной черты** (измерено: клиент заменяет полуширинную `|` внутри EditBox на символ той же длины — экспорт в 918 байт совпал с офлайн-рендером побайтово).

## Быстрый старт

1. Перетащите нужные навыки на панель действий
2. В игре введите `/eh go rescan`, чтобы аддон распознал слоты (`/eh go` — посмотреть результат распознавания)
3. **Привязка клавиши (рекомендуется, только клики)**: ПКМ по любому профилю (строка профиля в боевом интерфейсе или список в настройках) → управление профилем → выберите клавишу → [Сохранить]. **Альтернатива** для любителей макросов: `/run EVAL_GO()` одной строкой и перетащить на клавишу. ★**Привязки — по персонажу**: у каждого персонажа аккаунта свои клавиши (сверка выполняется автоматически при входе, чужие привязки с собой не переносятся).
4. Быстрый старт с шаблонов: окно настроек → вкладка «Макрос» → [Импорт/Экспорт] → **[Шаблоны]** — библиотека сгруппирована по классам, клик = импорт готового профиля, дальше подгоните под себя
5. **Впервые здесь?** Введите `/eh guide` — руководство из четырёх шагов (боевой интерфейс → первый профиль → привязка клавиши → журнал способностей); при первом входе оно показывается автоматически.
6. `/eh debug` — в чате показывается причина каждого решения при нажатии, удобно настраивать пороги

## Самопомощь при сбоях (при проблемах смотрите сюда)

1. **Сначала `/reload`**: навыки не распознаются, глючит интерфейс, только что обновили файлы аддона — в большинстве случаев перезагрузка всё чинит (конфиг сохранён и не пропадёт);
2. Навыки сменили позицию / новые перетащены на панель → `/eh go rescan` пересканировать;
3. Включите отладку и смотрите процесс решений → `/eh debug` (почему каждый навык кастуется / не кастуется, поусловно √×);
4. Не решено → заведите Issue на <https://gitee.com/xeval/emberveil_eval_help.git> (скриншот состояния `/eh st` + файл журнала сильно помогают локализации).
5. **Чужой профиль не применяет часть способностей**: обычно текстура ауры не изучалась на этой машине — теперь она ищется по имени и запоминается; `/eh go tex` — список, `/eh go texdel <имя>` — удалить одну, `/eh go texclear` — очистить;
