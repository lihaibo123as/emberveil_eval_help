# EvalHelp — Инструмент для всех классов

> 🌍 Языки: [中文](README.md) · [English](README_en.md) · **Русский**（язык в игре: флаги в правом верхнем углу окна настроек）

> Аддон-инструмент **для всех классов** EmberVeil (1.12.1 / Lua 5.1): тело макроса — одна строка `/run EVAL_GO()`, движок правил — **пять категорий навыков** (действия персонажа / навыки персонажа / поведение питомца / выбор цели / использование предметов) × **60 типов условий** (6 групп выпадающего списка: свои · цели · ауры · группа/рейд · навык/чтение · кандидат — 4 типа «кандидат», появляются только в строке выбора участника) × несколько профилей на разных клавишах. Полностью визуальная настройка, без привязки к классу. Плюс пять встроенных страниц: **Инструменты** (**UI-инструменты** · торговец · группа / общение · задания · три помощника · трансляция редких — **полный список строк в таблице ниже**), **Квесты и вещи** (цепочки · снаряжение · четыре вида поиска + слой меток на карте мира, нужен UnrealQuest), **Библиотека иконок** (встроенные иконки макросов клиента: группировка по префиксу, путь при наведении, поиск и постраничный просмотр), **Помощник питомцев** (способности → источник приручения → точки спауна) и **Суб-аддоны** (включение / отключение необязательных суб-аддонов).
>
> 📌 Текст правил (имена навыков / слова условий / импорт-экспорт) остаётся на языке клиента — переводится только оболочка интерфейса.

## 🏁 Вехи (1.52.0 → 1.75.60)

- **🖌 «Режим редактирования» тумана мира + отдельная база смещений + список аннотаций карты теперь выше карты** (1.75.60): перетаскивание каждого тайла прямо на карте (невыбранный тайл первым нажатием только выделяется — тянуть нужно вторым; правый клик в любом месте отпускает перетаскивание; Shift выделяет всю группу) · номера остаются видимыми, **наведение подсвечивает соответствующую рамку, а удержание начинает перетаскивание** · панель из десяти рядов (стрелки позиции · размер · выделение · **двухуровневый сброс** · переключатели вида · **общая прозрачность** · **Сохранить (запись на диск + перезагрузка)**); правки можно «запечь» в отдельную базу смещений (`MapOverlayOffset.lua`), поставляемую с аддоном (приоритет: сохранение > файл > нет); ★для всплывающего окна из карты нужен **хост `WorldFrame` + `FULLSCREEN_DIALOG` + вычисляемый уровень** — истинная причина в том, что **открытие полноэкранной карты скрывает UIParent** (фреймы внутри него вообще не рисуются, поднятие strata не помогает).

- **🗺️ Туманы мира переименованы в «Отключить туман мира» · оба переключателя карты по умолчанию сняты** (1.75.51 → 1.75.59): две строки в наборе инструментов → UI-инструменты приведены к формулировке пользователя (**снят = исходная карта клиента; включает только установленный флажок**, вторая строка переименована в «**Отключить туман мира**»), **оба по умолчанию не отмечены** (в прежних версиях по умолчанию было включено ⇒ при загрузке nil превращается в явный false и **об этом честно сообщается один раз**; если старая запись сама включала чистку остатков, этот явный выбор уважается); переключение любого из них показывает **окно «нужен /reload»** (единственная реализация `EVAL_RELOAD_ASK`, «Перезагрузить» идёт через `RunScript` в обход защищённого `ReloadUI`); весь туманный блок вынесен в отдельный модуль `tools/WorldFog.lua` (свой такт + своё поддерево настроек, **без жёсткой связи с масштабом карты**) с полным **порядком выключения** (вернуть ресурсы / реально снять такт: `MDQ.beatSync` — единственный вход, поэтому при выключенном по умолчанию не выполняется ни одного пустого такта / сбросить данные / убрать слои: свои скрыть, переиспользованные слоты вернуть по пяти параметрам, всё скрытое показать обратно); сдержана производительность (окно всплеска по собственной реальной подписи движка + повторное взведение ≥0.5 с + лимит кадров, сравнение перед записью ⇒ в устойчивом режиме нулевых записей).
- **🧹 Перетаскивание рамок: механизм обновления подтянут** (1.75.47 / 1.75.52): **рамки без пользовательских атрибутов больше не трогаются** (системные привязки, перенесённые без смещения, помечаются `axAuto` ⇒ страж / применение / маскировка их пропускают; след `dx/dy` по-прежнему считается настройкой); **маскировка подскока при открытии окна** (alpha в 0 → применить → измерить → вернуть пользовательскую alpha, никогда не оставляя невидимым навсегда); **[Сброс] теперь очищает и координаты блока, и базу размещения** («после сброса нижние панели уезжают» ⇒ очищаем ещё `base/cur`, перепроверка учитывает `axAuto`, перенос — только в режиме редактирования); после [Сброса] появляется окно «нужен /reload».

- **🐾 Помощник кормления: полоса прогресса наконец работает + оценка убывания в реальном времени + геометрия иконки**（1.75.42）：полоса **не отображалась ни разу с 1.75.10** — её условие автозапуска `EVAL_HH_ENABLED` **нигде не было определено** (движок ни разу не запускался; доказательство — в сохранённых переменных нет ключа `hhHappyProbe`) ⇒ теперь используется собственный общий выключатель файла `hhOn()`: процент выровнен по **измеренному уровню счастья** (0 / 33 / 66 / 100 — «зелёный → жёлтый» даёт ровно 66%), убывание **измеряется по уровням верности** (высшая верность 7.2 очка/с = 0.72%/с как опора, остальные уровни добираются измерением — **без выдуманных множителей**), полоса обновляется **каждые 0.2 с** (единая точка отрисовки / единый источник цвета / при выключении действительно снимается); геометрия иконки сведена к двум **одинаковым** чёрным слотам (нижняя полоса · квадрат 26×26 · картинка 18px по центру).

- **🎯 Редактор навыка: мультивыбор для условий аур** (1.75.39): десять условий buff/debuff (свои / цели + группа·рейд + кандидат) теперь принимают **несколько аур** (переключение нажатием, поиск, свой ввод; галочки сохраняются при закрытии и повторном открытии списка) — **достаточно любого выбранного** (ИЛИ); направление «нет / нехватка» — двойственное (**каждый** пункт должен требовать обновления, а не «одного хватает»); первая строка списка объясняет правило, подсказка на ячейке имени перечисляет все выбранные + направление, а лог и трассировка условий пишут «любой сработал → X» / «нужны все → X»; ★старые сохранения без миграции; ★**группу «изученные» теперь можно чистить выборочно** (1.75.58): **правый клик удаляет одну запись**, у каждой строки есть явный **✕**, а в конце группы — «✕ очистить изученные (N)»; список **обновляется сразу** (единственная реализация `EVAL_AURA_TEX_FORGET*`, общая для обоих путей записи; имя, которое сейчас выбрано, тоже убирается из выбора, а постоянная и рабочая таблицы меняются вместе, без учёта регистра).

## Быстрый старт

1. Перетащите нужные навыки на панель действий
2. В игре введите `/eh go rescan`, чтобы аддон распознал слоты (`/eh go` — посмотреть результат распознавания)
3. **Привязка клавиши (рекомендуется, только клики)**: ПКМ по любому профилю (строка профиля в боевом интерфейсе или список в настройках) → управление профилем → выберите клавишу → [Сохранить]. **Альтернатива** для любителей макросов: `/run EVAL_GO()` одной строкой и перетащить на клавишу.
4. Быстрый старт с шаблонов: окно настроек → вкладка «Макрос» → [Импорт/Экспорт] → **[Шаблоны]** — библиотека сгруппирована по классам, клик = импорт готового профиля, дальше подгоните под себя
5. **Впервые здесь?** Введите `/eh guide` — руководство из четырёх шагов (боевой интерфейс → первый профиль → привязка клавиши → журнал способностей); при первом входе оно показывается автоматически.
6. `/eh debug` — в чате показывается причина каждого решения при нажатии, удобно настраивать пороги

## Самопомощь при сбоях (при проблемах смотрите сюда)

1. **Сначала `/reload`**: навыки не распознаются, глючит интерфейс, только что обновили файлы аддона — в большинстве случаев перезагрузка всё чинит (конфиг сохранён и не пропадёт);
2. Навыки сменили позицию / новые перетащены на панель → `/eh go rescan` пересканировать;
3. Включите отладку и смотрите процесс решений → `/eh debug` (почему каждый навык кастуется / не кастуется, поусловно √×);
4. Не решено → заведите Issue на <https://gitee.com/xeval/emberveil_eval_help.git> (скриншот состояния `/eh st` + файл журнала сильно помогают локализации).
5. **Чужой профиль не применяет часть способностей**: обычно текстура ауры не изучалась на этой машине — теперь она ищется по имени и запоминается; `/eh go tex` — список, `/eh go texdel <имя>` — удалить одну, `/eh go texclear` — очистить;
