# EvalHelp — Инструмент для всех классов

> 🌍 Языки: [中文](README.md) · [English](README_en.md) · **Русский**（язык в игре: флаги в правом верхнем углу окна настроек）

> 📢 **Канал релизов (KOOK)**：[emberveil 一键宏 · 插件发布](https://www.kookapp.cn/app/channels/7071527711947717/5336773639081280) — **каждый релиз публикуется там** (отдельный пост для основного аддона и для каждого суб-аддона) с кратким описанием изменений, скриншотами и ссылками на скачивание.

> Аддон-инструмент **для всех классов** EmberVeil (1.12.1 / Lua 5.1): тело макроса — одна строка `/run EVAL_GO()`, движок правил — **пять категорий навыков** (действия персонажа / навыки персонажа / поведение питомца / выбор цели / использование предметов) × **71 типов условий** (7 групп выпадающего списка: свои · цели · ауры · группа/рейд · питомцы группы/рейда · навык/чтение · кандидат — 4 типа «кандидат», появляются только в строке выбора участника) × несколько профилей на разных клавишах. Полностью визуальная настройка, без привязки к классу. Плюс пять встроенных страниц: **Инструменты** (**UI-инструменты** · торговец · группа / общение · задания · три помощника · трансляция редких — **полный список строк в таблице ниже**), **Квесты и вещи** (цепочки · снаряжение · четыре вида поиска + слой меток на карте мира, нужен UnrealQuest), **Библиотека иконок** (встроенные иконки макросов клиента: группировка по префиксу, путь при наведении, поиск и постраничный просмотр), **Помощник питомцев** (способности → источник приручения → точки спауна) и **Суб-аддоны** (включение / отключение необязательных суб-аддонов).
>
> 📌 Текст правил (имена навыков / слова условий / импорт-экспорт) остаётся на языке клиента — переводится только оболочка интерфейса.

## 🏁 Вехи (1.52.0 → 1.76.6)

- **🧾 Новый инструмент «Журнал обменов» + 🛒 массовая покупка + 🎯 два новых типа условий (игрок-цель / цель цели) + 🖼️ рецепт рамки всплывающих окон стал общим стандартом проекта** (1.76.1): журнал обменов пристёгивается **справа от окна обмена** при каждом его открытии (время / партнёр / золото / иконки предметов · пролистывание колесом · ЛКМ — шёпот, ПКМ — удалить строку, [Очистить] — подтверждение вторым кликом); массовая покупка возможна потому, что у штатного окна торговца **вообще нет окна разделения стека** (клиентский `GetMerchantItemMaxStack` всегда 1) ⇒ перехват Shift+ПКМ **ничего не отнимает**; оба условия **при пустом имени подставляют ваше собственное** («цель цели» = танковое «моя цель смотрит на меня»), сравнение точное, и **любая неудача поиска честно возвращает «нет» — включая обратное направление**.
- **🪙 Столбец золота в журнале обменов, закрыт за четыре раунда (1.76.3 → 1.76.6, принято в игре: «функция работает»)** — от «золото всегда показывает —» до самой причины: ① **события о деньгах приходят по одному на сторону** (пара `MoneyTypeInfo` в собственном `MoneyFrame.lua` клиента: `PLAYER_TRADE_MONEY` покрывает только мою сторону, **`TRADE_MONEY_CHANGED` — чужую, и последнее мы никогда не регистрировали**); ② добавлен **второй путь чтения на чистом Lua** (без API движка) и разделены «**не читается**» и «**прочитан 0**»; ③ пустая ячейка обмена возвращает **поддельную ссылку, а не `nil`** (пустоту теперь определяем **линейкой самого клиента**); ④ панель прижата к окну обмена (замер: **1 логический пиксель = 2 пикселя изображения**) и исправлено «содержимое списка накладывается на серые строки»; ⑤ **самое неожиданное**: минус перед отданным золотом **вообще никогда не рисовался** — в шрифте клиента **нет глифа U+2212 «−»** (тихий пропуск символа) ⇒ столбец переведён на **ASCII красный `-` / зелёный `+`**, а в проект добавлен постоянный **шлюз «нет глифа»** (тот же символ тогда же ломал кнопки «W −» / «H −» в панели редактирования WorldFog).
- **⚔️ Два суб-аддона выпущены (1.76.2 / 1.76.6)**: **EH_DPS 0.2.6** исправляет «активное время уходит в минус» (межсессионная метка часов, восстановленная из сохранения, всё ещё использовалась как база разницы ⇒ прибавлялся отрицательный прирост, а порог «меньше секунды считаем за секунду» увеличил результат в 60 000 раз; три шлюза: откат часов · нормализация метки сессии · доверие к знаменателю); **EH_Damage 0.2.46 → 0.2.48** закрывает два **выхода за границы на этапе загрузки** (верхняя граница сканирования книги заклинаний теперь **читается на месте**, а жёсткая индексация таблицы метрик шрифта по уровням стала «**сначала спросить, есть ли оно и таблица ли это**») — обе причины из семейства «у других игроков падает на экране загрузки».
- **🎒 EH_Bag 0.3.49: оптимизация алгоритма «разложить сумки» — принят вариант A «парковка ближе к своему месту» (замер: −12,3 % шагов) + три переключаемых алгоритма (`a` / `b` / `orig`)** (1.76.0): порядок ходов и **все правила безопасности не изменены** — умнее стало только «куда парковать вытесненный предмет»: сначала в **его собственное конечное место** (если оно пусто), иначе прежнее «первое пустое». Замер на 8 наборах: **1029 → 902 шага (−12,3 %)**, а на крупном случае (сумки + банк) **−25 %** (255 → 192). **Нулевая регрессия**: итоговая раскладка **совпадает по клеткам**, **обменов 0**, по-прежнему одна пара `PickupContainerItem` за такт и полное перечитывание каждый шаг. Новая строка настроек **«Алгоритм сортировки»** + `/ebag algo a / b / orig` (`b` = более агрессивный необязательный «сначала пустые цели», замер **−38,3 %**; `orig` = исходный алгоритм, **сохранён как база»), а `/ebag algo` показывает средние секунды / шаги / предметы по каждому варианту — для собственного A/B.
- **🔇 Главный выключатель «журнала отладки» теперь по умолчанию ВЫКЛ + 📬 EH_Mail 0.3.19 → 0.3.23 (завершение страницы почтового журнала)** (1.75.119): ① в прошлой версии выключили не то — здесь затронут **настоящий выключатель**: всё, что аддон говорит в чат сам, теперь **по умолчанию молчит** (критерий — только печать «ты сам это трогал», поэтому обновление **никогда не перебивает твой выбор**; **эхо твоих собственных команд по-прежнему видно**, `/eh logdump` по-прежнему пишет). ## Быстрый старт

1. Перетащите нужные навыки на панель действий
2. В игре введите `/eh go rescan`, чтобы аддон распознал слоты (`/eh go` — посмотреть результат распознавания)
3. **Привязка клавиши (рекомендуется, только клики)**: ПКМ по любому профилю (строка профиля в боевом интерфейсе или список в настройках) → управление профилем → выберите клавишу → [Сохранить]. **Альтернатива** для любителей макросов: `/run EVAL_GO()` одной строкой и перетащить на клавишу. ★**Привязки — по персонажу**: у каждого персонажа аккаунта свои клавиши (сверка выполняется автоматически при входе, чужие привязки с собой не переносятся).
4. Быстрый старт с шаблонов: окно настроек → вкладка «Макрос» → [Импорт/Экспорт] → **[Шаблоны]** — библиотека сгруппирована по классам, клик = импорт готового профиля, дальше подгоните под себя
5. **Впервые здесь?** Введите `/eh guide` — руководство из четырёх шагов (боевой интерфейс → первый профиль → привязка клавиши → журнал способностей); при первом входе оно показывается автоматически.
6. `/eh debug` — в чате показывается причина каждого решения при нажатии, удобно настраивать пороги

## Самопомощь при сбоях (при проблемах смотрите сюда)

1. **Сначала `/reload`**: навыки не распознаются, глючит интерфейс, только что обновили файлы аддона — в большинстве случаев перезагрузка всё чинит (конфиг сохранён и не пропадёт);
2. Навыки сменили позицию / новые перетащены на панель → `/eh go rescan` пересканировать;
3. Включите отладку и смотрите процесс решений → `/eh debug` (почему каждый навык кастуется / не кастуется, поусловно √×);
4. Не решено → заведите Issue на <https://gitee.com/xeval/emberveil_eval_help.git> (скриншот состояния `/eh st` + файл журнала сильно помогают локализации).
5. **Чужой профиль не применяет часть способностей**: обычно текстура ауры не изучалась на этой машине — теперь она ищется по имени и запоминается; `/eh go tex` — список, `/eh go texdel <имя>` — удалить одну, `/eh go texclear` — очистить;
