# EvalHelp — Инструмент для всех классов

> 🌍 Языки: [中文](README.md) · [English](README_en.md) · **Русский**（язык в игре: флаги в правом верхнем углу окна настроек）

> 📢 **Канал релизов (KOOK)**：[emberveil 一键宏 · 插件发布](https://www.kookapp.cn/app/channels/7071527711947717/5336773639081280) — **каждый релиз публикуется там** (отдельный пост для основного аддона и для каждого суб-аддона) с кратким описанием изменений, скриншотами и ссылками на скачивание.

> Аддон-инструмент **для всех классов** EmberVeil (1.12.1 / Lua 5.1): тело макроса — одна строка `/run EVAL_GO()`, движок правил — **пять категорий навыков** (действия персонажа / навыки персонажа / поведение питомца / выбор цели / использование предметов) × **70 типов условий** (7 групп выпадающего списка: свои · цели · ауры · группа/рейд · питомцы группы/рейда · навык/чтение · кандидат — 4 типа «кандидат», появляются только в строке выбора участника) × несколько профилей на разных клавишах. Полностью визуальная настройка, без привязки к классу. Плюс пять встроенных страниц: **Инструменты** (**UI-инструменты** · торговец · группа / общение · задания · три помощника · трансляция редких — **полный список строк в таблице ниже**), **Квесты и вещи** (цепочки · снаряжение · четыре вида поиска + слой меток на карте мира, нужен UnrealQuest), **Библиотека иконок** (встроенные иконки макросов клиента: группировка по префиксу, путь при наведении, поиск и постраничный просмотр), **Помощник питомцев** (способности → источник приручения → точки спауна) и **Суб-аддоны** (включение / отключение необязательных суб-аддонов).
>
> 📌 Текст правил (имена навыков / слова условий / импорт-экспорт) остаётся на языке клиента — переводится только оболочка интерфейса.

## 🏁 Вехи (1.52.0 → 1.75.118)

- **🗑️ Новый инструмент «Авто-выброс»** (1.75.118): перетаскиваемая иконка «выброс» — **ПКМ по ней открывает выбор предметов прямо из сумок**, полоса справа: **ЛКМ** переключает, **ПКМ** убирает, Ctrl+колесо меняет размер иконки; выброс теперь идёт по **активной проверке сумок раз в секунду** (больше не ждёт событий сумок, поэтому мусор, уже лежащий в сумках, тоже вычищается), а каждый реальный выброс печатает **красную строку с кликабельной ссылкой на предмет** (не зависит от переключателя журнала отладки).

- **🆕 Новый суб-аддон EH_Mail (улучшения почты + проверка API), первый выпуск** (1.75.117 / EH_Mail 0.3.0 → 0.3.18): половина — **зонд проверки только для чтения** (`/email`, 114 имён клиента; первый прогон в игре: **ничего не отсутствует**, единственная реальная проблема — **переполнение индекса региона R11**, уже исправлена в порте; результат идёт в собственное ограниченное кольцо, а **через 6 секунд выполняется `/reload`** для сохранения); вторая половина — **портированное улучшение почты**: отправка нескольких вложений · массовые «забрать / вернуть / удалить» · **страница журнала в виде сетки иконок** (одна ячейка = одно письмо, при наведении — кому / тема / вложения / деньги / наложенный платёж / время, **клик переходит к написанию письма и подставляет адресата**) · история получателей на уровне аккаунта с автодополнением · **список вложений = чистые данные** (вы выбираете в сумках, ячейки вложений лишь отображают выбор ⇒ **во время выбора ни один предмет не берётся в руки**; предметы реально перемещаются только в момент нажатия «Отправить») · **закрытие почты аннулирует выбор** (наложение «вложение» на ячейках сумок и серость клиента убираются сразу). Префикс в чате теперь **`[EH_Mail]`**; журнал почты **по умолчанию выключен**, и учитывается только **ваш собственный** `/tm log` ⇒ обновление никогда не переопределяет ваш выбор.
- **🎯 Новый инструмент «здоровье цели» + аддон несёт собственную базу здоровья существ** (1.75.113 → 1.75.116): для враждебных целей клиент даёт **только процент**, поэтому аддон ищет существо по **имени + уровню** и пересчитывает настоящие числа (выборка **47/47 совпадает** с `health.max` официальной базы, **0 конфликтов** для пары (имя, уровень)); когда определить нельзя, показывается **только процент**, а не выдуманное число; подача дважды пересматривалась по скриншотам из игры и в итоге рисует **одну строку белых чисел по центру полосы здоровья цели самого клиента** (шрифт и цвет скопированы со фрейма игрока), у строки в инструментах есть `[настройки]` с множественным выбором (значение / процент), **по умолчанию включено**.
- **⏱️ Полоса таймера удара / автоатаки стала плавнее: тонкая полоса обновляется покадрово по необходимости, а тайминг дальнего боя больше не зависит от китайского/английского текста** (1.75.112): раньше полоса двигалась максимум раз в 0,15 с; теперь она обновляется каждый кадр **только там, где это действительно нужно** — условие: окно видно ∧ боевая секция включена ∧ идёт реальный отсчёт (`rem > 0.05`), и как только это перестаёт быть верным, кадр **снимает себя в том же кадре** (не висит постоянно, без `/reload`); для тайминга автоатаки дальнего боя добавлен **не зависящий от языка** канал событий (`ACTIONBAR_UPDATE_COOLDOWN`), который **сначала сам себя проверяет** (частота событий ÷ скорость атаки должна попадать в 0,75–1,25 при ≥4 попаданиях в диапазон), а всё непрошедшее проверку **не принимается вообще** — текстовый якорь продолжает работать; три живых A/B-прогона подтвердили, что принятый канал совпадает с событиями строка в строку.
- **🗡️ EH_Damage: боевые числа переработаны (0.2.37 → 0.2.43)**: наборы глифов выросли до **трёх наборов / девяти стилей** (5 параметрических обводок на встроенном шрифте · 9c оригинал · древнее уся), а в панели теперь отдельные шаговые поля **Набор глифов** и **Стиль обводки**; параметры сгруппированы в **Движение · Позиция · Глиф · Анимация масштаба**, сетка галочек стала **3 колонки**, фон панели теперь **полностью непрозрачный** (числа больше не просвечивают); **предел амплитуды крита 100% → 200%**; исправлены «жёлтые блоки» в панели (разделитель 1 px у заголовка группы никогда не получал размер из-за `pcall` без `self` ⇒ клиент рисовал его в размере по умолчанию ≈32×32 как золотой квадрат); плюс два реальных скриншота и документация (код времени выполнения не менялся).

## Быстрый старт

1. Перетащите нужные навыки на панель действий
2. В игре введите `/eh go rescan`, чтобы аддон распознал слоты (`/eh go` — посмотреть результат распознавания)
3. **Привязка клавиши (рекомендуется, только клики)**: ПКМ по любому профилю (строка профиля в боевом интерфейсе или список в настройках) → управление профилем → выберите клавишу → [Сохранить]. **Альтернатива** для любителей макросов: `/run EVAL_GO()` одной строкой и перетащить на клавишу. ★**Привязки — по персонажу**: у каждого персонажа аккаунта свои клавиши (сверка выполняется автоматически при входе, чужие привязки с собой не переносятся).
4. Быстрый старт с шаблонов: окно настроек → вкладка «Макрос» → [Импорт/Экспорт] → **[Шаблоны]** — библиотека сгруппирована по классам, клик = импорт готового профиля, дальше подгоните под себя
5. **Впервые здесь?** Введите `/eh guide` — руководство из четырёх шагов (боевой интерфейс → первый профиль → привязка клавиши → журнал способностей); при первом входе оно показывается автоматически.
6. `/eh debug` — в чате показывается причина каждого решения при нажатии, удобно настраивать пороги

## Самопомощь при сбоях (при проблемах смотрите сюда)

1. **Сначала `/reload`**: навыки не распознаются, глючит интерфейс, только что обновили файлы аддона — в большинстве случаев перезагрузка всё чинит (конфиг сохранён и не пропадёт);
2. Навыки сменили позицию / новые перетащены на панель → `/eh go rescan` пересканировать;
3. Включите отладку и смотрите процесс решений → `/eh debug` (почему каждый навык кастуется / не кастуется, поусловно √×);
4. Не решено → заведите Issue на <https://gitee.com/xeval/emberveil_eval_help.git> (скриншот состояния `/eh st` + файл журнала сильно помогают локализации).
5. **Чужой профиль не применяет часть способностей**: обычно текстура ауры не изучалась на этой машине — теперь она ищется по имени и запоминается; `/eh go tex` — список, `/eh go texdel <имя>` — удалить одну, `/eh go texclear` — очистить;
