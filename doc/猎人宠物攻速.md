## 一、一句话结论（口径）

**★1.12 的宠物攻速是「按生物个体」而不是「按家族」定的。** Petopia Classic 攻速页原文：
*"pets retain their native attack speeds when tamed. This means that two pets tamed from different wild NPCs may have different attack speeds, even though they're physically identical."*

⇒ 同一个家族横跨多档（猫科 **1.0~2.0**、熊 **2.0~2.5**），而有些家族**一只快的都没有**（迅猛龙/猪/鳄鱼/螃蟹/乌龟/风蛇/猩猩/猫头鹰 = 100% 2.0）。
所以本插件**给家族区间 + 给个体值**，**绝不给家族一个单一数字**（那是错的）；查不到就显示「?」，**绝不默认 2.0**。

**★攻速快 ≠ DPS 高**：同家族内快宠每次伤害等比更低，DPS 相同（Petopia 明文）。快攻速的用处是 **PvP 打断施法 / 压对方驱散者的蓝 / 维持狂乱 / 触发类效果**。

★**为什么宠物列表能纳入「详情页没有的宠物」**：技能详情页的行只来自转录的「谁教这个技能」表（237 只），
而宠物列表读的是 **552 条个体表** ⇒ 迪舒/影爪/死亡之喉/狮王休玛/迷雾嚎叫者/毁灭/阿拉加/暮色巡游者/希洛塔姆/血色猎犬…
这 12 只具名稀有全部在列（技能列改显示它们的家族天生技能）。

- **唯一读法** `phSpdOf(name)`：`beast[名]` → `alias[名]` 再查一次 → `fix[名]`；都没有 = `nil`（显示「?」）。
- **生成物字段**：`all`（**全量 552 条个体，生成期按攻速升序排好** = 宠物列表的唯一数据源）· `bsk`（宠物名 → 转录表里实际教的技能）· `alias`（13 条旧译）· `fix`（2 条定案值）· `fam`（家族区间）· `named`（19 只具名）· `frenzy`（阈值/点数）· `fast`（1.7）。
- **★名字 → 速度的索引在运行期建一次**（`phSpdIdx` 从 `all` 现建、缓存）⇒ 生成物里**故意不再输出**「名字→速度」映射（一处真值、少一半体积）。
- **命令**（活路径，不是孤儿读值口）：`/eh go 宠物家族 攻速`（别名 `/eh pet fam 攻速`）= 摊开 17 家族区间 + 19 只逐只明细；`/eh go 宠物家族 表` 每行追加「攻速 x~y 秒/次」。读数照旧落有界环 `cfg.petProbe`。
- **狂乱天赋点数**（来源 17173 / uiwow 1.12 百科）：攻速 **<1.4 → 3 点** · **<1.6 → 4 点** · **≥1.6 → 5 点**（可全程维持）。★边界：原文「1.4 到 1.6 需要 4 点」与「1.6 及以上 5 点」在 **1.6 这一个点**上自相矛盾 ⇒ 本插件取「1.6 归 5 点」。

## 七、边界与未验证项（如实）

1. **口径是 Classic 1.13 的实测数据**（Petopia），四条中文来源都标 1.12 且逐条一致 ⇒ 大概率同真值；但**本服 EmberVeil 是否魔改**只能真机抽验：抓一只表里 1.5 的（例如**迪舒**）或 2.0 的，观察攻击节奏是否与表相符。
   ★本客户端**有官方 API `UnitAttackSpeed(unit)`**（`api_unit.html` 文档：任意 UnitID，单位不存在返回 0），Petopia 官方查怪攻速用的就是 `/run UnitAttackSpeed("target")` ⇒ 若将来想「实时读目标攻速」，一条探针即可定案（**本轮按用户要求不做**）。
2. **ZG 团本怪**（觅血蝙蝠 1.0 / 疯狂的觅血蝠 1.0 / 玛尔里的爪牙 1.4 / 祖利安徘徊者 1.6）**能否抓未验证**；「哈卡之子 1.0」是谣言（实为 2.0）。
3. **攻速快 ≠ 更强**：同家族 DPS 相同（见 §一）。
4. **表外 = 2.0** 只是「Petopia 该页列出的是全部可驯服个体」这一前提下的推论；本插件对**查不到的名字显示「?」而不是 2.0**，不替数据下结论。
5. 稀有标记来自**本服库 `rnk`**（552 条中 114 条有标记：稀有 60 / 精英 49 / 稀有精英 5），与「社群公认稀有」不完全一致（例：辛达尔）。
6. ★★★**「块插错位置」这一类错只能靠静态顺序审计**（1.75.37 首版真机红字 `PetHelper.lua:248 attempt to call global 'phFamById' (a nil value)`）：
   宠物列表块被插在 `phFamById` **声明之前** ⇒ 块内调用的是**全局 nil**。★两条教训：
   ① `luacheck` 扫不到（它能解析、名字合法）；
   ② **harness 的桩反而会掩盖它**（我把 `phFamById` 桩成全局 ⇒ 离线全绿、真机红字）⇒ 桩只验证**行为**，不验证**作用域**；
   ⇒ 现在有两道离线防线：harness 的「抽取块依赖声明顺序」检查（带阴性对照）· `node probe_localorder.js`（默认清单已含 `PetHelper.lua` 等 11 个主力文件）。
   **动手规矩**：往文件里插**大块代码**前，先列出这块**用到的所有文件级 local**，逐个确认声明行在块之前。
