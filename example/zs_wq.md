# 方案: 武器战

> EVAL_HELP 技能方案（v1.8.0+），与游戏内「导入导出 → 武器战示例」内容一致。
>
> 导入方法：游戏内 `/eh cfg` → 战士 → **[导入导出]**（或 `/eh war io`），
> 把下方技能行全选复制（Ctrl+C）粘贴（Ctrl+V）进输入框，点「导入为新方案」。
>
> 格式约定：
> - 每行一条技能规则：`- 技能名 | 条件`
> - 条件之间：`&` = 同组全部满足才放；`|` 分隔的组之间任一满足即放
> - 条件前缀 `!` = 取反；技能名前加 `!` = 该技能停用（导入后默认关闭）
> - 技能必须在动作条上（按图标比对），改过动作条后 `/eh war rescan`
> - 行顺序 = 释放优先级（上面的先判定）

## 技能规则

- 压制 | 怒气>5 & 可用 & 就绪
- 战斗怒吼 | 怒气>9 & 无buff:战斗怒吼
- 断筋 | 目标血<30 & 怒气>9 & 无debuff:断筋
- 撕裂 | 可流血 & 目标血>10 & 怒气>9 & 无debuff:撕裂
- 血性狂暴 | 战斗中 & 无buff:血性狂暴 & 就绪
- 猛击 | Alt & 怒气>20
- 英勇打击 | 怒气>30 & 未排队

## 条件词表

| 写法 | 含义 |
|---|---|
| 怒气>30 / 能量>30 | 怒气/能量数值（支持 > >= < <= == ~=） |
| 目标血<30 | 目标血量百分比 |
| 自身血>50 | 自身血量百分比 |
| 能量%>10 | 能量百分比 |
| 进战>3 | 进战秒数 |
| 战斗中 / 非战斗 | 战斗状态 |
| 可攻击 / 可流血 | 目标可攻击 / 可流血（Cat 黑白名单） |
| 精英 / Boss | 目标分级 |
| 目标战斗中 | 目标在战斗 |
| 普攻 | 自动攻击已开 |
| Alt / Shift / Ctrl | 修饰键按住 |
| 姿态1 / 非姿态1 | 当前姿态序号 |
| 无buff:战斗怒吼 | 自身没有该 buff（图标比对） |
| 有buff:血性狂暴 | 自身有该 buff |
| 无debuff:断筋 | 目标没有该 debuff |
| 有debuff:撕裂 | 目标有该 debuff |
| 就绪 | 冷却就绪 |
| 可用 | IsUsableAction（压制类） |
| 未排队 | 未排进下次普攻（英勇/猛击类） |
