## 它是干什么的

EmberVeil 的官方 API 索引（`api_*.html`）**只收客户端 C API，不收 FrameXML 函数/具名帧**；
客户端资源又在压缩的 UE pak 里（原始字节扫描搜不到东西，**不能**当否证）。
⇒ 「客户端有没有 `MailFrame` / `SendMailFrame_Update` / `InboxFrame_Update` 这些**名字**」离线判不了，
**只能真机判**。本子插件就是那把尺子：

* 逐个判定 **114 个**客户端名字在不在（分类见下），结果写进**它自己的**有界落盘环；
* 判定完 **6 秒后自动 `/reload`** 落盘（本客户端 SavedVariables 只在 `/reload`/退出时写盘）；
* 聊天只回 **3 行**（结论 / 缺失点名 / 倒计时），全量明细走 `/email 明细`；
* **全程只读**：不改任何游戏状态、不碰任何客户端全局、不建常驻帧、不挂事件。

## 命令

| 命令 | 作用 |
|---|---|
| `/email`（别名 `/eh邮件`） | 跑一次体检（只读）→ 落盘环 + 6 秒后自动 `/reload` |
| `/email 明细` | 把落盘环摊开到聊天（全量，按写入顺序） |
| `/email 状态` | 一行简报：上次体检时间 / 缺几项 / 环里几条 |
| `/email 清` | 清空落盘环 |
| `/tm`（别名 `/ehmail`） | **邮箱增强（移植版）**的命令（邮箱增强本体，见下节；日志默认开启，`/tm log` 切换） |

★ 本插件在聊天框里的**播报前缀统一是 `[EH_Mail]`**（= 插件目录名，0.3.17 起；移植版内部表名 / 文件名仍是上游的
`EHMailTM*`，那只是代码里的名字，不会出现在聊天里）——与 `[EH_Bag]` / `[EH_Damage]` / `[EH_DPS]` / `[EH_DebugBox]` 同一口径。

## 邮箱增强（移植版）（邮箱增强）

0.2.0 起**内置 邮箱增强（移植版）**（原插件来自 TurtleWoW；作者 shirsig/sica · 游侠汉化 · 小疯子修改）。
**勾选启用后邮箱界面自动变成增强版，不需要敲任何命令**：

* **收件箱**：多选、批量取件 / 批量退回 / 批量删除、分类筛选，外加第 3 个页签「日志」；
* **写邮件**：多附件（一封一个附件、可连发多封）、收件人历史下拉与自动补全、COD 相关便捷按钮；
* **日志**：**小图标方格**一屏看全（见下「日志页 = 小图标方格」），鼠标停在图标上看这一封的全部信息，点一下就能回信 / 再寄；
  仍可按人·类型·日期区间筛选（含日历控件）。

### 批量面板 = 默认收起（0.3.16）

* 收件箱页「接收所有邮件」右边那颗按钮 = **展开 / 收起批量面板**：按钮左侧是**自绘的金色小图标**
  （一个「面板」的样子：外框 + 两条短横线），右侧的金色箭头 `»`（已展开）/ `«`（已收起）跟着状态变
  （鼠标停在按钮上也会写明这一步是展开还是收起）。
  ★按钮**大小与以前一模一样**（不会越过邮箱边框）；图标是本插件自己画的，不依赖任何图标文件。
* ★**默认是收起的**（0.3.16）：面板不再一开邮箱就自动弹出来占地方。**手动展开过一次就会记住**，下次开邮箱照上次的样子。
* 面板里是**分类筛选（勾选框）+ 批量取件 / 批量退回 / 批量删除 + 「本页全选」**。
  ★**不用这个面板也能干活**：每封邮件前面那颗勾选框照旧可用，「接收选择邮件」按你勾中的那些取件。

### 附件选择列表（0.3.11 起；0.3.12 补「拖放 / 发件前清理」）

* **右键背包物品** = 把那一件**加进选择列表**（再右键同一件 = 移出）；列表里的条目会铺在写邮件页那排附件格上。
* ★**拖着物品松手落在附件格上**（0.3.12）= 那一件**加进选择列表**，并且**这次拖拽会被取消**（东西放回原格、光标清空）
  —— 不用先放下再右键。「选择物品列表」那个小计数框上松手也一样。
  ★**判不出它是从哪一格拖来的**（比如从银行主格或装备栏拖出来的）⇒ **一件都不会加**，只在聊天里如实说一句。
* ★**点【发送】前会先看光标**（0.3.12）：光标上还拖着东西 ⇒ 先**放回原处**再寄；认不出它的家 ⇒ **一件都不寄**并提示你手动放下。
  （本插件**绝不清光标** —— 清掉就等于把东西弄丢。）
* **只读体检**：`/tm 附件 光标`（别名 `拖拽`）= 摊开「光标上有没有东西 / 锁着的格子是哪些 / 认不认得出它的家」，**零副作用**。
* ★**附件框里有信息引导**（0.3.13）：鼠标停在**附件格**或右边那个**计数框**上，气泡里会写清怎么用
  —— **首选做法是直接在背包里完成**：右键物品 = 加入 / 再右键 = 移出；`Alt+左键` = 同种物品批量加入
  （不用把东西拖到这儿）。想拖也行：拖到附件格上松手 = 加入 + 自动取消这次拖拽。
  同一份引导也可以用 **`/tm 附件 帮助`** 打到聊天框里。
* ★**快速删除**（0.3.13）：**删一条 = 点那一个附件格**（左键 / 右键都行）；**整批清空 = 右键那个计数框**
  —— 两种都**只从列表里移除**，背包里的东西一件不动（清完会如实报清掉几条）。
* ★**装了「背包整合」（EH_Bag）时**：进了列表的那件物品，在**背包格**上会盖一层半透明的「**附件**」标记
  （从列表移走就当场消失）—— 一眼能看出哪些东西已经被选去当附件。
* ★**关掉邮箱 = 附件选择自动清干净**（0.3.15）：选好东西之后**一关邮箱**，选择列表当场作废
  —— 背包格上的「**附件**」标记与「锁定/变灰」一起消失，聊天里如实报一句
  「邮箱已关闭 ⇒ 已清空附件选择列表 N 条（背包里的东西一件都没动）」。
  ⇒ 下次开邮箱是**从零开始选**；**关闭邮箱不会动背包里的任何一件东西**、也不会碰你的光标。
  本来就是空的时候关邮箱 ⇒ **一个字的提示都不会有**。

### 日志页 = 小图标方格（0.3.14）

* 「日志」页签（**已收到** / **已发送**）改成**小图标方格**：**一格 = 一封邮件**，9 列 × 10 行 = 一屏 90 格
  （照工具箱「图标库」的布局形式）。图标优先用邮件里那件**物品的贴图**，没有就依次退回拍卖行图章 / 退回图章 / 通用便签。
* **鼠标停在图标上** = 这一封的全部信息：**对方**（谁寄来 / 寄给谁）· 主题 · **附件** · **金币** · 到付 · 时间，
  末行还写明「点一下会做什么」。图标**右上角**的小图章 = 拍卖行 / 退回；**右下角**的小色块 = 到付（橙）/ 有钱（金）。
* ★**点一下图标 = 直接进入写邮件页，并把「对方」填进收件人** —— 已收到那页就是给**来信的人**回信，
  已发送那页就是**再寄给当初的收件人**。
  ★拍卖行 / 系统寄来的邮件**没有对方** ⇒ 只切页面并如实说一句（**绝不编一个名字填进去**）。
* 滚动条与滚轮 = **按行翻**，上下按钮 = 一整页；状态行显示「共 N 封 ｜ 当前显示第 a-b 封」。
  日志为空时一个格子都不留残影。

### 移植时改了什么（与上游的差异）

| # | 改动 | 为什么 |
|---|---|---|
| ① | 插件名判断 `上游插件` ⇒ `EH_Mail`（`ADDON_LOADED` 的 `arg1` 与 `GetAddOnMetadata`） | 客户端发的是**本插件真名**；不改 ⇒ 初始化整段不执行（看着载入了、界面却毫无变化） |
| ② | 三处 `[{金额框:GetRegions()}][9]` ⇒ 「够才设」 | 本客户端该控件**只有 4 个 region**，原写法会 nil 索引，并**中断载入期后续 3 个初始化** |
| ③ | **pfUI 皮肤整条剔除**（皮肤文件 / XML 引用 / 调用） | 本机没有 pfUI；按「只移植原始 UI 的功能」处理 |
| ④ | 自带贴图路径 ⇒ `Interface\AddOns\EH_Mail\` | 目录名变了；不改 ⇒ 三道贴图**静默画空** |
| ⑤ | 三处存档全局不再「无条件覆盖」，改成「缺什么补什么」 | 原版每次载入都会把刚恢复的存档覆盖掉 ⇒ **日志历史 / 自动补全名字 / 收件人历史每次登录清空** |
| ⑥ | ★★**不再提供窗口拖拽**（整窗注册与标题栏柄都撤掉，位置也不再自己记） | 收件箱 / 写信页的空白处曾整片是拖拽热区 ⇒ **在邮箱里任意地方一按就可能开始拖窗口**；要挪窗口请用**宿主工具箱 → 拖拽图层**（那里有成熟的柄与位置守护） |
| ⑦ | 日志改成**未读邮件也记**，并去掉「同一封反复打开重复入账」 | 原条件只记「已读 / 手动点开」的 ⇒ **批量取件时一条都不记**，日志页看着永远空 |

★ **存档**：本子插件只用**两个**存档根（toc 里的 `EH_MAIL_CFG` 账号级 + `EH_MAIL_CHAR` 角色级），
上游那 9 个存档键作为它们的**字段**存在（`EHMailTM_Saved.lua` 的代理转发）。
★**收件人历史（通讯录）按「账号」保存** —— 同一账号下所有角色共用同一份，换角色不用重新加。
★**本客户端的 `## SavedVariables` 一行只认一个名字** —— 写成 `A B C` 会被当成一个超长名字写进存档，
读回来就是语法错、每次登录弹红框（这也是为什么要收成两个根）。
与宿主 `EvalHelp` 的存档**完全分开**——本子插件**不读不写** `EVAL_HELP_CONFIG` / `EVAL_HELP_CHAR`。

## 体检的 8 个类别（114 项）

> ★ `REGIONS` 组**不进总数**（它是判据组、不是名字清单）⇒ 114 = 22+46+7+21+5+8+5（名字与模板）。

| 类别 | 项数 | 判法 | 缺失意味着 | 首轮真机 |
|---|---|---|---|---|
| `FUNC` | 22 | `type(_G[名]) == "function"` | **前 10 个 = 上游插件 挂钩点**：缺任一 ⇒ 它一开邮箱就红字（R1） | ✅ 全在 |
| `FRAME` | 46 | `rawget(_G,名) ~= nil` | 客户端邮件窗的具名控件，缺 ⇒ 对应 `SetPoint`/`Show` 会报错 | ✅ 全在 |
| `MISC` | 7 | 同上 | `DEFAULT_CHAT_FRAME` / `GameTooltip` / `UIPanelWindows` 等辅助全局 | ✅ 全在 |
| `CONST` | 21 | 同上 | 全局字符串常量（多为一行为文案；`ITEM_OPENABLE` 参与逻辑） | ✅ 全在 |
| `FONT` | 5 | 同上 | 字体对象（`NumberFontNormal` 等） | ✅ 全在 |
| `PARENT` | 8 | 同上 | **`$parent` 派生名**（静态 grep 天生看不见，只能运行期探，R4） | ✅ 全在 |
| `TEMPLATE` | 5 | `pcall(CreateFrame, "Frame", nil, UIParent, 模板名)` | XML 模板，缺 ⇒ 插件 XML 载入失败（R3） | ✅ 全在 |
| `REGIONS` | 6 | 每条带「**源码要取的下标**」⇒ 报 `N=x 要取[n] 可及/★越界` | **R11 判据**：越界 = 源码裸索引 `[N]` 必然 nil 索引 | ❌ 3 处越界 |

> 唯一非只读动作 = `TEMPLATE` 探针要**建临时帧**试一次（1.12 **没有销毁帧的 API**）⇒
> 建出来当场 `Hide` 且不留引用，并在聊天里如实报「探针临时帧 N 个」。

## 怎么读结论

AI 直接读存档即可，不用玩家转述：
`%LOCALAPPDATA%\Azeroth\Saved\Account\<账号>\SavedVariables\EH_Mail.lua` → 表 `EH_MAIL_CFG.probe`
（账号目录不固定 ⇒ 取所有账号里 mtime 最新那份；脚本 = `tmp/read_ehmailprobe.js`）。

| 读数 | 结论 |
|---|---|
| `缺 0 项` | ✅ 名字层全在（首轮真机即是此）；R1/R3/R4 结论 = 排除 |
| **`REGIONS` 报「★越界」** | ❌ **R11 必修**：源码裸索引 `[N]` 会在插件载入期 nil 索引 ⇒ 中断它后面的 load；改法 = 包 `pcall` 或先判可及 |
| 缺 `FUNC` 里任一挂钩全局 | ❌ R1：必须给它加 `type()` 守卫 |
| 缺 `SendMailMoney*Right` | ⚠️ R2：它的写邮件页加载会中断 |
| 缺 `FriendsFrameTabTemplate` | ⚠️ R3：第 3 页签/XML 载入失败 |
| 缺 `PARENT` 组 | ⚠️ R4：按缺失的点名定位到具体控件 |

## 边界（如实说）

* 本子插件**不读也不写宿主存档**（`EVAL_HELP_CONFIG` / `EVAL_HELP_CHAR` 命中 0 处），
  只用自己那份 `EH_MAIL_CFG`（toc 里 `## SavedVariables`）。
* 体检**只报「在不在」**，不报「行为对不对」——「在」不等于「表现和 TurtleWoW 一致」；
  真机跑一遍 上游插件 看红字/看界面仍是最终判据。
* 不判断第三方插件冲突（例如以后启用 unrealUI 的邮件皮肤）。
