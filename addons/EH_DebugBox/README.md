# EH_DebugBox 图层调试子插件

EmberVeil 客户端的**图层调试/取证**工具：枚举世界地图（及可选的 UIParent/WorldFrame/小地图簇等扫描源）的全部图层，以**可折叠树**展示，支持查看/修改各层的缩放、透明度、宽高、坐标，并把自定义落到账号级存档。

> 本插件是 EvalHelp 的独立子插件（自带 `.toc`，单独载入）；修改记录见同目录 `CHANGELOG.md`。

## 打开方式

- `/edb ui` —— 打开图层调试面板（也可从配置窗「子插件」入口）。
- `/edb` —— 打印全部命令。

## 面板功能地图

- **层列表（可折叠树）**
  - 行左侧 ▼/▶ = 折叠/展开这棵子树（只有父节点显示；折叠状态落存档，跨 `/reload` 保持）；
  - 缩进按**扫描时写下的层号**（不是数路径里的 `/`）；「层深」按钮 = 一次展开到第 N 层（循环 1→2→3→4→全部）。
- **选择机制**
  - **点层单元 = 单选**（再点已单选的同一层 = 取消）；
  - **左侧多选框 = 唯一的多选入口**（勾选/取消互不影响）；
  - 「全选结果 / 清空选择」按钮在底部第三排。
- **扫描（底部第四排）**
  - **无选中** = 全量重枚举所有勾选的扫描源；
  - **有选中** = **只深挖选中目标的子树**（不受层深 4 上限，可无限往下挖；兄弟分支不扫，省性能）；清空选择再点 = 回全量。
- **扫描源多选**：地图（默认）/ 界面 UIParent / 世界层 / 小地图簇 / 提示框 / 聊天窗 / 玩家框 / 动作条 / 背包 / 任务图钉。
- **过滤**：文字过滤 · 分类 · 只显示有名（默认开，区域/合成名一律算无名）· 仅显示中 · ≥500 · 层深 · 事件/脚本过滤（多选）。
- **改层参数**（底部一/二排）：缩放 / 透明 / 宽 / 高（各自可勾选是否应用）+ X/Y 坐标偏移；「应用外观 / 应用坐标 / 应用全部 / 还原坐标」。
- **自定义记账**：改过的层记录到账号级存档（含**首次改动前的原始值**），行左显色块+同色描边；「清理自定义」按原始值还原，「重设自定义」把存档重新铺到层上。
- **悬停**：地图上红框标出该层 + 自绘信息面板（路径/尺寸/父级/脚本挂载/已注册事件/自定义参数）。

## 常用诊断命令

| 命令 | 作用 |
|---|---|
| `/edb list` | 递归打印全部层（编号/名字/类型/尺寸/能否缩放），落存档 `EH_DEBUGBOX_CFG.layers` |
| `/edb grab` | 全自动采集（自开图 → 扫描 → 自关图 → 落盘） |
| `/edb scanui` | 通用 UI 扫描可行性测量（只读） |
| `/edb scan` | 重扫（同面板「扫描」按钮：有选中 = 深挖子树） |
| `/edb named` | 无名层过滤诊断（条目/有名/无名/列表条数） |
| `/edb tree` | 图层树诊断；`tree all` 全展开 / `tree none` 全折叠 |
| `/edb bars`（别名 `frames`） | 框体探针（动作条/队伍/团队/被动打开层候选逐个报在不在，落存档 `dragBars`） |
| `/edb t 编号 0.7` / `/edb off` | 只缩那一层 / 全部回 1 |

## 本客户端的已知坑（改代码前先看）

1. **帧是 userdata，但 `type(帧)` 会报 `"table"`**——`rawget(帧, ...)` 照样抛「table expected, got userdata」。读行条目**只能**走 `uiRowEntry()`（pcall rawget → 失败退字段读）。
2. **点子按钮会连带触发父行 OnClick**——行 OnClick 必须用 `GetMouseFocus()` 做焦点守卫。
3. 存档在账号级 `SavedVariables/EH_DebugBox.lua`（`EH_DEBUGBOX_CFG`）；`/reload` 才落盘。
4. 悬停 tooltip 在本面板宿主下 GameTooltip/WorldMapTooltip 都不渲染 ⇒ 一律自绘（`uiTipShow`）。
