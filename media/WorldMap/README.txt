「打开世界迷雾」自带贴图放这里（可选 —— 放了就完全自包含，不放就用客户端自带的那份）

目录约定（与表里的键一一对应）：
    media\WorldMap\<地图文件名>\<区域名><块号>.<扩展名>
例：
    media\WorldMap\Barrens\DRYGULCHRAVINE1.tga
    media\WorldMap\Tirisfal\BRIGHTWATERLAKE1.tga

规则（代码在 tools\SimpleMap.lua 的 MDQ.probeTex / MDQ.srcOf / MDQ.texPath）：
1. **自带优先**：`Interface\AddOns\EvalHelp\media\WorldMap\...` 只要能加载就用它；加载不出来才退回
   客户端自带的 `Interface\WorldMap\<地图>\<区域><块号>`（1.12 客户端的探索层美术）。
2. **两份都加载不出来 ⇒ 这一张图不接管**（不渲染、不藏原生层，并把以前藏过的原生层当场还回），
   只在聊天框如实说一次「本客户端加载不出这批贴图」。依据 = 项目铁律「拿不到证据就一个字节都不碰」：
   宁可保持客户端原样，也绝不画出一片空白图。
3. **判不出就放拦**：每个写法都配一张**同目录、同后缀、不可能存在**的对照路径（负对照）。对照也说「有」
   ⇒ 说明本客户端**读不出「文件在不在」**（它对不存在的文件也报尺寸）⇒ 该写法判不出，**一律退回客户端那份**
   （= 一直可用的行为）。依据：拿不到证据就一个字节都不碰，绝不改走一条可能不存在的自带路径
   （否则整张图会被画空 —— 这正是「去迷雾贴图没生效」的那种症状）。

写法（后缀）：插件目录里的散装文件**要写扩展名**（同 `media\Flags\<名>.tga`），所以自带那份按
`.blp` → `.tga` → 不写 依次试；客户端自带美术在归档里，**不写扩展名**（上游 S_WorldMap 同款）。
放贴图时**保留原扩展名**即可（`<区域><块号>.blp` 最省事，也不用转格式）。

体检命令（只读、零副作用）：
    /ehm mapfit 贴图
它会把「引擎自报的贴图路径」（`GetMapOverlayInfo(i)`）与「我们拼的两条路径（自带那份每种写法各一行）」并排列出来，
并逐条给探针结果（加载得出来 / 探不到 / 判不出），再给出**选中写法**与结论（用自带 / 用客户端 / 不接管），
最后一行是**探针可信度**（负对照的结果 —— 判「判不出」就说明这台客户端无法用探针判断文件在不在）。

贴图从哪来：这批美术是**客户端资源**（1.12 的探索层贴图，TurtleWoW 里打在 `Data\interface.MPQ`，
EmberVeil/UE 里打在 `Content\Paks\*.pak`），磁盘上**没有** `Interface\WorldMap` 这种目录 —— 想导出
得用 MPQ/pak 解包工具，并且属于暴雪美术资源，随插件分发前请自行确认许可。
