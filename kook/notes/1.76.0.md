**本次更新要点**（v1.76.0）

- 本次更新内容集中在子插件「**背包整合**」，一键整理的速度有明显提升（详见下面那段）。
- 主插件本版只随包升级版本号，功能与上一版一致；重载后照常使用。

## EH_Bag

- **一键整理更快了**：同样一堆东西，整理的总步数平均**少 12.3%**；东西越多越明显 —— 「背包 + 银行」共 150 件时从 **255 步降到 192 步（少 25%）**，满配 88 格从 130 步降到 115 步。按默认 0.2 秒一步算，一次大整理大约从 206 秒缩到 180 秒。
- ★**整理规则一个字没变**：先搬什么、往哪搬、什么情况下不动手，全部照旧；唯一的变化是「目标格被占用时，优先把占位的那件放回它自己该在的位置」，少走了回头路。
- ★**绝对不会出现「两格互换」**：整理永远只做两件事 —— 搬进空格、并入同一物品的堆；不会把两件东西对调，也不会把物品留在鼠标上（这是丢件的根源）。
- ★**三档算法可切换**：设置菜单里新增「**整理算法**」一行，点一下在 **A（默认 · 就近放回）→ B（更激进，实测还能再快一截）→ 原算法（与老版本一字不差）** 之间循环；也可以用命令 `/ebag algo a` / `b` / `orig` 切。
- ★**整理到一半切换也立刻生效**，不需要重载；如果配置里读到不认识的值，会自动按「原算法」跑（拿不准就走老路）。
- ★**实测记账**：敲 `/ebag algo` 会告诉你当前用的是哪一档，以及各档的**平均耗时 / 步数 / 件数**（只统计真正跑完的那一轮）；`/ebag algo clear` 可以清空这些数字。整理完成时那一行也会带上算法名，一眼看得出这轮用的哪一档。
